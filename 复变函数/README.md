# 复变函数考试模拟系统

一套**本地运行的复变函数考试模拟工具**：从题库随机抽题、浏览器作答、
题面中的复数**图形化渲染**（复平面 canvas：模、辐角、共轭、单位根），
交卷后服务端用**精确复数运算**判分，并给出逐题解析与错题复盘。

另有两条专门服务「基本功」的支线：

- **闪电训练** —— 把复数的表示与运算拆成随机小题反复快问快答，
  **答错立刻重做，答对才算过**，按知识点自动加权、跨轮次记错题本；
- **复平面实验台** —— 输入任意复数，看清「模 + 辐角」的几何意义，
  动画演示「复数乘法 = 旋转 + 伸缩」。

零第三方依赖（Python 标准库 + 原生 JavaScript），断网可用，
成绩与作答记录都留在本机。

## 快速开始

**Windows**：双击 `web_exam/start.bat`（本系统只需 Python，无需 gcc）。

**WSL / Linux / macOS**：

```bash
cd web_exam
./start.sh
```

启动脚本会检查 `python3`、检测端口占用并自动打开浏览器。
浏览器打开后先看到起始页，点 **“开始考试”** 才开始 120 分钟倒计时。

停止服务：在启动脚本窗口按 `Ctrl + C`。
换端口用 `./start.sh 9000`，只启动不开浏览器用 `./start.sh --no-open`。
默认端口 `8767`（与线代模板的 8766 互不冲突，可同时运行）。

三个入口：

| 页面 | 地址 | 作用 |
|------|------|------|
| 模拟卷 | `/` | 100 分限时模拟考试 |
| 闪电训练 | `/drill.html` | 复数基本功的肌肉记忆训练 |
| 复平面实验台 | `/plane.html` | 复数的几何直觉与乘法动画 |

## 考试流程

1. **起始页** —— 显示抽题号、题量构成、考试时间，此时不计时
2. **开始考试** —— 点按钮后计时启动、试卷展开
3. **作答** —— 选择/判断题点选项；填空题直接输入答案（支持 `3/4`、`0.75`、
   `3+4i`、`-i`、`√13`、`π/4`）；计算题按小问分别作答，右侧**同步画出复平面预览**
4. **实时得分** —— 左侧栏随作答即时更新当前得分（只回总分，不泄露对错）
5. **交卷评分** —— 服务端精确判分，弹出成绩单与逐题解析
6. **保存记录** —— 成绩与错题清单写入 `web_exam/records/`

中途刷新页面：倒计时按真实时间继续，作答不丢（localStorage）。

## 精确判分：为什么不用浮点

复数运算没有浮点近似，判分内核 `bank/complex_ref.py` 用**有理数 + 根式 + π**
的形式实数域做精确运算：

```
Real  = Fraction(有理部分) + Σ c·√d + c·π      （d 取无平方因子的正整数）
复数  = (实部, 虚部)，两个 Real
```

于是下面这些都能**精确**判定，不存在误差：

| 题面 | 标准答案 | 判分说明 |
|------|----------|----------|
| `(1+i)/(1-i)` | `i` | 有理化后精确相等 |
| `\|3+2i\|` | `√13` | 根式精确相等 |
| `\|3+4i\|` | `5` | 完全平方数 |
| `3e^{iπ/6}` | `3√3/2 + 3/2i` | 根式与分数精确相等 |
| `Arg(1+i)` | `π/4` | π 的有理倍数精确相等 |
| `(1+i)^8` | `16` | 快速幂精确计算 |

学生写法很宽松：`1/2` 与 `0.5` 等价，`3 + 4i` 与 `3+4i` 等价，
`√13` 与 `√13` 写法可带空格，`45°` 也接受（自动换算成 π 的倍数）。

## 闪电训练：把基本功练成肌肉记忆

这一页是本系统针对「复数的表示与运算」的**专项训练器**：

- **题目随机生成**：由 `bank/drill_gen.py` 按种子即时生成，
  覆盖加减乘除、共轭与倒数、模与辐角、指数形式↔代数形式、幂与根、
  棣莫弗公式六类，**题目无限不重复**，答案由精确运算现算，不会抄错；
- **答错立刻重做**：答错立刻排回队列，这一轮必须**答对才算过**，
  一轮结束前不会放过任何一道错题；
- **即时反馈**：每次作答立刻给出对错、正确答案与推导过程；
- **按知识点加权**：每个知识点记一个掌握度（0~5 级），
  越不熟的知识点下一轮出题越多；
- **错题本跨轮次保留**：答错的题存在服务端 `records/drill_wrongbook.json`，
  连续两次答对才移出；也可以只练错题本。

左栏实时显示本轮已练题数、答对/答错次数、连续答对数与各知识点掌握度。

## 复平面实验台

- 输入 z₁、z₂，在复平面上标出 **z₁、z₂、共轭 z̄₁、乘积 z₁z₂、商 z₁/z₂**，
  画出模半径、辐角弧、实虚部投影虚线，悬停可读出坐标、模与辐角；
- **乘法几何动画**：勾选「演示乘法几何」后播放，直观看到
  「乘 z₂ = 旋转 arg z₂ + 伸缩 |z₂|」；
- **棣莫弗公式**：输入 z 与 n，画出 z, z², …, zⁿ 的轨迹（模按 n 次方增长、
  辐角按 n 倍旋转）；
- **n 次单位根**：单位圆上等分点，n ∈ {1,2,3,4,6} 时标注精确值。

## 图形化复数能力

| 位置 | 能力 |
|------|------|
| 题面 | 复平面 canvas：坐标轴与网格、点、模半径、辐角弧、投影虚线、共轭对称点、单位根；悬停显示「z = 3+2i，\|z\| ≈ 3.606，arg ≈ 33.69°」 |
| 计算题作答 | 带小问标签的输入表格 + 实时复平面预览，写完立刻看到自己答案的「位置」 |
| 复平面实验台 | 独立的图形实验室，含乘法动画、幂轨迹、单位根 |

## 题库与抽题

题库共 **76 题**，每次开考随机抽 **32 题**组成一份 100 分的试卷：

| 大题 | 入库 | 每卷抽取 | 每题 | 每卷分值 | 判分方式 |
|------|------|----------|------|----------|----------|
| 一、选择题 | 24 | 10 | 3 分 | 30 | 选项比对 |
| 二、判断题 | 20 | 8 | 2 分 | 16 | 对 / 错比对 |
| 三、填空题 | 20 | 8 | 3 分 | 24 | 精确比对（全对得分） |
| 四、计算题 | 12 | 6 | 5 分 | 30 | 逐小问精确比对，按比例给分 |

- 抽题以**随机种子**为唯一依据：同一 seed 必得同一份试卷，
  刷新页面或重启服务都不会换卷；点“换一套题”才重新抽。
- 答案、解析与复核规则全部留在服务端，**前端拿不到**。
- 计算题按**答对小问的比例**给分（而不是整题对错）。
- 知识点分布上，「复数的表示、模与辐角、四则运算、共轭与倒数、幂与根、
  棣莫弗公式」六项基础占 69.7%，其余为 §2.1 的初等函数与概念。

覆盖知识点：复数的代数形式 / 指数形式 / 三角形式互化、模与辐角（arg 与 Arg）、
共轭与倒数、四则运算（尤其有理化除法）、整数幂与开方、方程 zⁿ = w 的根、
棣莫弗公式、单位根、复指数 eᶻ、复对数 log z 与支路、复幂 zᵅ 与幂律失效、
复三角与双曲函数、复变函数的概念与映射。

## 维护题库

试卷、答案、总览都由 `bank/` 派生，**不要直接改生成物**：

```bash
cd 考试服务
# 1. 按 bank/FORMAT.md 修改或新增题目
python build_paper.py     # 重新生成 paper.md / answer_key.md / bank_overview.md
python verify_paper.py    # 必须全部通过
```

`verify_paper.py` 会做四类检查：

1. 题库结构自查（题量、id 唯一、字段完整、图形规格与 `[[key]]` 标记可解析、
   知识点标签合法、答案可被精确解析）；
2. **答案机械复核**：能用精确运算重算的题目全部重算
   （模、辐角、四则运算、幂、共轭、倒数、方程根、单位根、模的平方）；
3. 抽题逻辑（每卷 32 题 100 分、同种子可复现、不同种子不同卷）；
4. 闪电训练题源（随机生成的答案必须都能被精确解析）。

改动判分逻辑后还要跑一遍端到端测试：

```bash
cd 考试服务
python web_exam/tests/complex_ref_test.py    # 运算内核自测（无需服务）
python web_exam/server.py 8799 &              # 先起服务
python web_exam/tests/api_test.py 8799        # 全流程接口测试
```

端到端测试覆盖：抽题可复现与答案隔离、整卷渲染前提、实时得分、
满分 / 零分卷、等价写法（分数加空格）、逐小问比例给分、
闪电训练判分与错题本增删、记录保存。

## 考后复盘

每次交卷后点“保存答题记录”，然后：

```bash
cd 考试服务/web_exam
python review.py             # 自动取最新一条记录，生成错题精讲
python review.py records/xxx.json   # 或指定记录
```

`review.py` 按抽题号复原试卷，逐题给出题面（复平面图解转成文字描述）、
你的作答、正确答案与解析，输出到 `records/` 下。

## 说明

- 服务只监听 `127.0.0.1`，不对外网开放。
- 本工具面向**个人自测与练习**，不具备监考能力。
- 端口 8767 与仓库里的线代模板（8766）不同，可以同时跑，互不干扰。
- 架构参考同仓库 `考试服务_模板/`（线性代数考试模拟系统）：
  相同的题库 / 抽题 / 判分 / 记录分层与接口约定；
  差异点是判分内核 —— 线代版用分数矩阵比对，本版改为
  **有理数 + 根式 + π 的精确复数运算**，并新增闪电训练与复平面图形。
