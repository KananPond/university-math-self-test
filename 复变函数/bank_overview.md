## 一、选择题（入库 24 题）

### c_cv_01（复数的表示，3 分）

复数 z = 1 + i 在复平面上的位置如 

> 复平面图解： z = 1 + i；|z| = √2；Arg z = π/4 所示，它的三角形式是（　　）。

- A. √2(cos π/4 + i sin π/4)
- B. √2(cos π/3 + i sin π/3)
- C. 2(cos π/4 + i sin π/4)
- D. √2(cos π/4 - i sin π/4)

**答案：`A`（√2(cos π/4 + i sin π/4)）**

> 解析：|z| = √(1² + 1²) = √2。z 在第一象限且 tan θ = 1/1 = 1，故 θ = π/4，于是 z = √2(cos π/4 + i sin π/4)。常见错误是把模写成 2，或把虚部符号取反。

### c_cv_02（复数的表示，3 分）

复数 z = 3 + 4i 的指数形式是（　　）。

- A. 5e^{i arctan(4/3)}
- B. 4e^{i arctan(3/4)}
- C. 5e^{i arctan(3/4)}
- D. 5e^{-i arctan(4/3)}

**答案：`A`（5e^{i arctan(4/3)}）**

> 解析：|z| = √(3² + 4²) = 5，arg z = arctan(4/3)。故 z = 5e^{i·arctan(4/3)}。易错点是把模算成 4，或把 arctan 的分子分母颠倒。

### c_cv_03（复数的表示，3 分）

复数 z = 2(cos π/3 + i sin π/3) 的代数形式是（　　）。

- A. 1+√3i
- B. √3+i
- C. 1-√3i
- D. 2+√3i

**答案：`A`（1+√3i）**

> 解析：实部 = 2cos π/3 = 2 × (1/2) = 1，虚部 = 2sin π/3 = 2 × (√3/2) = √3，所以 z = 1 + √3i。

### c_cv_04（复数的表示，3 分）

在复平面上，复数 z = x + yi 对应的点是（　　）。

- A. 点 (x, y)
- B. 点 (y, x)
- C. 点 (-x, -y)
- D. 点 (x, -y)

**答案：`A`（点 (x, y)）**

> 解析：取实轴为横轴、虚轴为纵轴建立复坐标系，则 z = x + yi 对应点 (x, y)：实部对应横坐标，虚部对应纵坐标。

### c_cv_05（模与辐角，3 分）

复数 z = 3 + 4i 的模 |z| 是（　　）。

- A. 5
- B. 7
- C. 25
- D. √7

**答案：`A`（5）**

> 解析：|z| = √(x² + y²) = √(3² + 4²) = √25 = 5。注意模要开方，把 x² + y² = 25 直接当模是典型错误。

### c_cv_06（模与辐角，3 分）

复数 z = -1 - i 的主值辐角 Arg z 是（　　）。

- A. -3π/4
- B. 3π/4
- C. 5π/4
- D. -π/4

**答案：`A`（-3π/4）**

> 解析：z 在第三象限，tan θ = (-1)/(-1) = 1。主值范围是 (-π, π]，第三象限对应 -3π/4，故 Arg z = -3π/4。写成 5π/4 就超出了主值范围。

### c_cv_07（模与辐角，3 分）

复数 z = i（如 

> 复平面图解： z = i；|z| = 1；Arg z = π/2）的所有辐角组成的集合是（　　）。

- A. {π/2 + 2kπ | k ∈ Z}
- B. {π/2 + kπ | k ∈ Z}
- C. {π/2}
- D. {kπ | k ∈ Z}

**答案：`A`（{π/2 + 2kπ | k ∈ Z}）**

> 解析：arg z 是多值的：arg z = Arg z + 2kπ = π/2 + 2kπ (k ∈ Z)。若取 π/2 + kπ，则 k = 1 时得到 3π/2，那是 -i 的辐角，不是 z 的辐角。

### c_cv_08（四则运算，3 分）

复数 (1 + i)(1 - i) 等于（　　）。

- A. 2
- B. 2i
- C. 0
- D. -2

**答案：`A`（2）**

> 解析：(1+i)(1-i) = 1 - i + i - i² = 1 + 1 = 2。这也是共轭相乘的经典值 |1+i|² = (√2)² = 2。

### c_cv_09（四则运算，3 分）

复数 (1 + i)/(1 - i) 等于（　　）。

> 复平面图解： z₁ = 1 + i，z₂ = 1 - i，z₁z₂ = 2

- A. i
- B. -i
- C. 1
- D. 2i

**答案：`A`（i）**

> 解析：分子分母同乘分母的共轭 (1+i)：(1+i)(1+i)/((1-i)(1+i)) = (1+2i+i²)/(1-i²) = 2i/2 = i。关键是先有理化，直接约分是高频错点。

### c_cv_10（四则运算，3 分）

复数 1/(1 + i) 等于（　　）。

- A. 1/2-1/2i
- B. 1/2+1/2i
- C. 1-i
- D. 1+i

**答案：`A`（1/2-1/2i）**

> 解析：1/(1+i) = 1·(1-i)/((1+i)(1-i)) = (1-i)/2 = 1/2 - 1/2i。若忘记乘共轭因子就会误选 1-i。

### c_cv_11（四则运算，3 分）

复数 (2 + 3i)/(1 - i) 等于（　　）。

> 复平面图解： z₁ = 2 + 3i，z₂ = 1 - i，z₁z₂ = 5 + i

- A. -1/2+5/2i
- B. 1/2+5/2i
- C. -1/2-5/2i
- D. 5/2-1/2i

**答案：`A`（-1/2+5/2i）**

> 解析：(2+3i)/(1-i) = (2+3i)(1+i)/((1-i)(1+i)) = (2+2i+3i+3i²)/(1-i²) = (-1+5i)/2 = -1/2 + 5/2i。

### c_cv_12（共轭与倒数，3 分）

复数 z = 3 - 4i 的共轭复数 z̄ 是（　　）。

- A. 3+4i
- B. 3-4i
- C. -3+4i
- D. -3-4i

**答案：`A`（3+4i）**

> 解析：共轭复数只把虚部变号：z̄ = x - yi = 3 + 4i。它在复平面上与 z 关于实轴对称，且 |z̄| = |z| = 5。

### c_cv_13（共轭与倒数，3 分）

复数 1/(2i) 等于（　　）。

- A. -i/2
- B. i/2
- C. -2i
- D. 2i

**答案：`A`（-i/2）**

> 解析：1/(2i) = 1·(-2i)/((2i)(-2i)) = -2i/4 = -i/2。用公式 1/z = z̄/|z|² 也一样：z̄ = -2i，|z|² = 4。

### c_cv_14（幂与根，3 分）

复数 i 的 2025 次幂 i^{2025} 等于（　　）。

- A. i
- B. -i
- C. -1
- D. 1

**答案：`A`（i）**

> 解析：i 的幂以 4 为周期：i, -1, -i, 1, i, …。2025 = 4×506 + 1，故 i^{2025} = (i⁴)^{506}·i = 1^{506}·i = i。

### c_cv_15（幂与根，3 分）

复数 (1 + i)^8 等于（　　）。

- A. 16
- B. 16i
- C. -16
- D. 8

**答案：`A`（16）**

> 解析：(1+i)² = 2i，(1+i)⁴ = (2i)² = -4，(1+i)⁸ = (-4)² = 16。这些经典值要背下来。

### c_cv_16（幂与根，3 分）

方程 z² = -1 的一个根是（　　）。

> 复平面图解： 半径为 1 的圆上的 2 次单位根：1、-1

- A. i
- B. -i
- C. 1
- D. -1

**答案：`A`（i）**

> 解析：由 i² = -1 知 z = ±i 都是方程的根；二次方程在复数域上恰有两个根，它们互为相反数，都落在单位圆上。

### c_cv_17（棣莫弗公式，3 分）

由棣莫弗公式，(cos π/3 + i sin π/3)³ 等于（　　）。

- A. -1
- B. 1
- C. i
- D. -i

**答案：`A`（-1）**

> 解析：(cos θ + i sin θ)³ = cos 3θ + i sin 3θ。取 θ = π/3，则 3θ = π，cos π + i sin π = -1。

### c_cv_18（复指数函数，3 分）

复数 e^{πi/2} 等于（　　）。

- A. i
- B. -i
- C. 1
- D. -1

**答案：`A`（i）**

> 解析：e^{iθ} = cos θ + i sin θ，故 e^{πi/2} = cos π/2 + i sin π/2 = 0 + i = i。它是单位根之一。

### c_cv_19（复指数函数，3 分）

设 z = x + yi，则 |e^z| 等于（　　）。

- A. e^x
- B. e^y
- C. e^{x+y}
- D. 1

**答案：`A`（e^x）**

> 解析：e^z = e^x(cos y + i sin y)，所以 |e^z| = e^x·√(cos²y + sin²y) = e^x。复指数的模只由实部决定，实部为负时模也小于 1。

### c_cv_20（复对数函数，3 分）

取主值分支时，Log(-1) 的值是（　　）。

- A. iπ
- B. -iπ
- C. π
- D. -π

**答案：`A`（iπ）**

> 解析：Log z = ln|z| + i·Arg z。|-1| = 1，Arg(-1) = π ∈ (-π, π]，故 Log(-1) = ln 1 + iπ = iπ。

### c_cv_21（复对数函数，3 分）

复数 z（z ≠ 0）的对数 log z 的所有值组成的集合是（　　）。

- A. {ln|z| + i(arg z + 2kπ) | k ∈ Z}
- B. {ln|z| + i·Arg z}
- C. {ln|z| + 2kπ | k ∈ Z}
- D. {arg z + 2kπ | k ∈ Z}

**答案：`A`（{ln|z| + i(arg z + 2kπ) | k ∈ Z}）**

> 解析：复对数是多值的：log z = ln|z| + i(arg z + 2kπ) = ln|z| + i(Arg z + 2kπ)，k ∈ Z。取主值只得到其中一个值 Log z = ln|z| + i·Arg z，其余各值相差 2kπi。

### c_cv_22（复幂函数，3 分）

按主值定义 z^α = e^{α Log z}，则 (-1)^{1/2} 的主值是（　　）。

- A. i
- B. -i
- C. 1
- D. -1

**答案：`A`（i）**

> 解析：Log(-1) = iπ，故 (-1)^{1/2} = e^{(1/2)·iπ} = e^{iπ/2} = cos π/2 + i sin π/2 = i。全部值为 ±i，其中 i 是主值。

### c_cv_23（复三角与双曲函数，3 分）

复变函数 sin z = 0 的全部解是（　　）。

- A. z = nπ (n ∈ Z)
- B. z = nπi (n ∈ Z)
- C. z = (n + 1/2)π (n ∈ Z)
- D. z = n (n ∈ Z)

**答案：`A`（z = nπ (n ∈ Z)）**

> 解析：sin z = (e^{iz} - e^{-iz})/(2i) = 0 ⟺ e^{iz} = e^{-iz} ⟺ e^{2iz} = 1 ⟺ 2iz = 2kπi ⟺ z = kπ。所以零点恰是全体整数倍的 π。

### c_cv_24（复变函数概念，3 分）

设 w = f(z) = z²，z = x + yi，则 w = u(x, y) + iv(x, y) 中的 u(x, y) 与 v(x, y) 是（　　）。

- A. u = x² - y², v = 2xy
- B. u = x² + y², v = 2xy
- C. u = 2xy, v = x² - y²
- D. u = x² - y², v = -2xy

**答案：`A`（u = x² - y², v = 2xy）**

> 解析：(x + yi)² = x² + 2xyi + y²i² = (x² - y²) + 2xyi，所以 u = x² - y²，v = 2xy。复变函数 w = f(z) 本质上就是一对实值函数 u(x, y) 与 v(x, y)。

## 二、判断题（入库 20 题）

### j_cv_01（复数的表示，2 分）

复数 z 与它的共轭复数 z̄ 在复平面上关于实轴对称。

**答案：对**

> 解析：z = x + yi 对应点 (x, y)，z̄ = x - yi 对应点 (x, -y)，两点关于实轴对称。相应地 |z̄| = |z|。

### j_cv_02（复数的表示，2 分）

复数 z = 3 + 4i 在复平面上对应的点是 (3, 4)。

**答案：对**

> 解析：实轴为横轴、虚轴为纵轴，实部 3 对应横坐标，虚部 4 对应纵坐标，故对应点为 (3, 4)。

### j_cv_03（模与辐角，2 分）

arg z 与 Arg z 是同一个概念。

**答案：错**

> 解析：arg z 是多值的：arg z = Arg z + 2kπ (k ∈ Z)；Arg z 是主值，取在 (-π, π] 内。两者含义不同，不能混用。

### j_cv_04（模与辐角，2 分）

主值辐角 Arg z 的取值范围是 (-π, π]。

**答案：对**

> 解析：定义 Arg z 为 arg z 中落在 (-π, π] 内的那个值。注意负实轴上的点（如 z = -1）取 Arg z = π 而不是 -π。

### j_cv_05（模与辐角，2 分）

对任意复数 z = x + yi，都有 |z| = √(x² + y²)。

**答案：对**

> 解析：|z|² = z·z̄ = (x + yi)(x - yi) = x² + y²，故 |z| = √(x² + y²) ≥ 0。

### j_cv_06（四则运算，2 分）

(1 + i)(1 - i) = 2i。

**答案：错**

> 解析：(1+i)(1-i) = 1 - i + i - i² = 1 + 1 = 2，即 |1+i|² = 2，不是 2i。

### j_cv_07（四则运算，2 分）

复数除法必须先把分母有理化，即分子分母同乘分母的共轭复数。

**答案：对**

> 解析：对 a/b，分子分母同乘 b̄ 得 a·b̄/|b|²，这正是 1/b = b̄/|b|² 的应用。只适用于 b ≠ 0。

### j_cv_08（共轭与倒数，2 分）

当 z ≠ 0 时，1/z = z̄/|z|²。

**答案：对**

> 解析：由 z·z̄ = |z|²，两边同除 |z|² 得 z̄/|z|² = 1/z。该式是复数除法有理化的依据。

### j_cv_09（共轭与倒数，2 分）

|z̄| = |z| 对任何复数 z 都成立。

**答案：对**

> 解析：|z̄|² = x² + (-y)² = x² + y² = |z|²，两者非负故 |z̄| = |z|。

### j_cv_10（幂与根，2 分）

i⁴ = 1，且对任意整数 k 有 i^{4k+1} = i。

**答案：对**

> 解析：i, i² = -1, i³ = -i, i⁴ = 1，之后按 4 循环。i^{4k+1} = (i⁴)^k·i = i。

### j_cv_11（幂与根，2 分）

(1 + i)⁴ = -4。

**答案：对**

> 解析：(1+i)² = 1 + 2i + i² = 2i，(1+i)⁴ = (2i)² = 4i² = -4，再平方得 (1+i)⁸ = 16。

### j_cv_12（棣莫弗公式，2 分）

(cos θ + i sin θ)ⁿ = cos nθ + i sin nθ 对任意正整数 n 都成立。

**答案：对**

> 解析：这就是棣莫弗公式。由它可推出 z = r(cos θ + i sin θ) 时 zⁿ = rⁿ(cos nθ + i sin nθ)，是求幂与开方的基础工具。

### j_cv_13（复指数函数，2 分）

复指数函数 e^z 是周期函数，周期为 2πi。

**答案：对**

> 解析：e^{z+2πi} = e^z·e^{2πi} = e^z·1 = e^z，故 2πi 是它的周期。

### j_cv_14（复指数函数，2 分）

方程 e^z = 0 在复数域中有解。

**答案：错**

> 解析：e^z = e^x(cos y + i sin y)，其中 e^x > 0 且 cos y + i sin y ≠ 0，故 e^z ≠ 0 恒成立，方程无解。

### j_cv_15（复对数函数，2 分）

对任意 z₁ ≠ 0, z₂ ≠ 0，恒有 log(z₁z₂) = log z₁ + log z₂。

**答案：错**

> 解析：复对数多值，正确关系是 log(z₁z₂) = log z₁ + log z₂ + 2kπi，是否相等取决于支路的选取。例如取主值时 log(-1) + log(-1) = 2iπ，而 log((-1)(-1)) = log 1 = 0，相差 2πi。

### j_cv_16（复对数函数，2 分）

取主值分支时，Log z = ln|z| + i·Arg z，其中 Arg z ∈ (-π, π]。

**答案：对**

> 解析：由 e^{ln|z| + i Arg z} = |z|(cos Arg z + i sin Arg z) = z 可得。以负实轴为割线切开复平面即得主值分支。

### j_cv_17（复幂函数，2 分）

幂律 (z^α)^β = z^{αβ} 对任意 z ≠ 0 和任意复数 α、β 恒成立。

**答案：错**

> 解析：反例：按主值定义 ((-1)²)^{1/2} = 1^{1/2} = 1，而 (-1)^{2·(1/2)} = -1，两者不等。原因是取 Log 时引入了 2kπi 的多值性。

### j_cv_18（复三角与双曲函数，2 分）

sin z = 0 当且仅当 z = nπ (n ∈ Z)。

**答案：对**

> 解析：sin z = (e^{iz} - e^{-iz})/(2i) = 0 ⟺ e^{2iz} = 1 ⟺ 2iz = 2kπi ⟺ z = kπ。这与实数情形一致，是棣莫弗公式的推论。

### j_cv_19（复三角与双曲函数，2 分）

sin z 在虚轴上有界。

**答案：错**

> 解析：由 |sin z|² = sin²x + sinh²y，在 x = 0 处 |sin(iy)| = |sinh y| → ∞ (y → +∞)，故 sin z 在虚轴上无界，确界为 ∞。

### j_cv_20（复变函数概念，2 分）

确定一个复变函数 w = f(z)，必须同时说明其定义域 D 与对应关系。

**答案：对**

> 解析：复变函数是定义在复平面某区域 D 上、取值于复平面的对应关系，记作 w = f(z)，z ∈ D。其值域为 f(D) = {f(z) : z ∈ D}。

## 三、填空题（入库 20 题）

### f_cv_01（复数的表示，3 分）

复数 z = 2(cos π/3 + i sin π/3) 的实部是 ______。

**答案：**`1`

> 解析：实部 = r cos θ = 2cos π/3 = 2 × (1/2) = 1。

### f_cv_02（复数的表示，3 分）

复数 z = 2(cos π/3 + i sin π/3) 的代数形式是 ______。

**答案：**`1+√3i`

> 解析：实部 = 2cos π/3 = 1，虚部 = 2sin π/3 = 2 × (√3/2) = √3，所以 z = 1 + √3i。

### f_cv_03（模与辐角，3 分）

复数 z = 1 + 2i 的模是 ______。

> 复平面图解： z = 1 + 2i；|z| = √5；Arg z = （不可精确表示）

**答案：**`√5`

> 解析：|z| = √(x² + y²) = √(1² + 2²) = √5。

### f_cv_04（模与辐角，3 分）

复数 z = 3 + 4i 的模的平方 |z|² 是 ______。

**答案：**`25`

> 解析：|z|² = x² + y² = 3² + 4² = 25；相应的 |z| = 5。

### f_cv_05（模与辐角，3 分）

复数 z = 1 + i 的主值辐角 Arg z 是 ______（用 π 的倍数表示）。

**答案：**`π/4`

> 解析：z 在第一象限，tan θ = 1/1 = 1，故主值 Arg z = π/4 ∈ (-π, π]。

### f_cv_06（模与辐角，3 分）

复数 z = -1 - i 的主值辐角 Arg z 是 ______（用 π 的倍数表示）。

**答案：**`-3π/4`

> 解析：z 在第三象限，tan θ = 1。主值范围 (-π, π]，故 Arg z = -3π/4（写成 5π/4 就不是主值了）。

### f_cv_07（模与辐角，3 分）

复数 z = cos π/6 + i sin π/6 的主值辐角 Arg z 是 ______（用 π 的倍数表示）。

**答案：**`π/6`

> 解析：z 的模为 1，辐角为 π/6（第一象限内 tan θ = (1/2)/(√3/2) = 1/√3），故 Arg z = π/6。

### f_cv_08（四则运算，3 分）

复数 (1 + i)/(1 - i) 等于 ______。

**答案：**`i`

> 解析：(1+i)/(1-i) = (1+i)(1+i)/((1-i)(1+i)) = (1+2i+i²)/(1-i²) = 2i/2 = i。除法先乘分母的共轭有理化是关键步骤。

### f_cv_09（四则运算，3 分）

复数 1/(1 + i) 等于 ______。

**答案：**`1/2-1/2i`

> 解析：1/(1+i) = 1·(1-i)/((1+i)(1-i)) = (1-i)/2 = 1/2 - 1/2i。

### f_cv_10（四则运算，3 分）

复数 (2 + 3i)/(1 - i) 等于 ______。

**答案：**`-1/2+5/2i`

> 解析：(2+3i)/(1-i) = (2+3i)(1+i)/((1-i)(1+i)) = (2+2i+3i+3i²)/(1-i²) = (-1+5i)/2 = -1/2 + 5/2i。

### f_cv_11（共轭与倒数，3 分）

复数 z = 3 - 4i 的共轭复数 z̄ 是 ______。

**答案：**`3+4i`

> 解析：共轭复数把虚部变号：z̄ = x - yi = 3 + 4i；它与 z 关于实轴对称。

### f_cv_12（共轭与倒数，3 分）

复数 z = 2i 的倒数 1/z 等于 ______。

**答案：**`-i/2`

> 解析：1/(2i) = 1·(-2i)/((2i)(-2i)) = -2i/4 = -i/2；也可用 1/z = z̄/|z|² = (-2i)/4 = -i/2。

### f_cv_13（幂与根，3 分）

复数 (1 + i)^8 等于 ______。

**答案：**`16`

> 解析：(1+i)² = 2i，(1+i)⁴ = (2i)² = -4，(1+i)⁸ = (-4)² = 16。

### f_cv_14（棣莫弗公式，3 分）

(cos π/4 + i sin π/4)⁴ 等于 ______。

**答案：**`-1`

> 解析：由棣莫弗公式 (cos θ + i sin θ)⁴ = cos 4θ + i sin 4θ，取 θ = π/4 得 cos π + i sin π = -1。也可直接算：(√2/2 + √2/2 i)² = i，再平方得 i² = -1。

### f_cv_15（棣莫弗公式，3 分）

(cos π/6 + i sin π/6)³ 等于 ______。

**答案：**`i`

> 解析：(cos θ + i sin θ)³ = cos 3θ + i sin 3θ，θ = π/6 时 3θ = π/2，故值为 cos π/2 + i sin π/2 = i。

### f_cv_16（复指数函数，3 分）

复指数函数 e^z 的一个周期是 ______。

**答案：**`2πi`

> 解析：e^{z+2πi} = e^z·e^{2πi} = e^z·1 = e^z，所以 2πi 是 e^z 的周期（也是它的基本周期）。

### f_cv_17（复对数函数，3 分）

取主值分支时，Log i 的值是 ______。

**答案：**`iπ/2`

> 解析：Log z = ln|z| + i·Arg z。对 z = i：|i| = 1，Arg i = π/2，故 Log i = ln 1 + i·π/2 = iπ/2。

### f_cv_18（复幂函数，3 分）

按主值定义 z^α = e^{α Log z}，则 (-1)^{1/2} 的全部值是 ______（写出任意一个即可）。

**答案：**`i` 或 `-i`

> 解析：log(-1) = ln 1 + i(π + 2kπ) = i(2k+1)π，故 (-1)^{1/2} = e^{(1/2)i(2k+1)π} = ±i。答 i 或 -i 均可。

### f_cv_19（复三角与双曲函数，3 分）

复变函数 sin z = 0 的最小正实数解是 ______（用 π 的倍数表示）。

**答案：**`π`

> 解析：sin z = (e^{iz} - e^{-iz})/(2i) = 0 ⟺ e^{2iz} = 1 ⟺ 2iz = 2kπi ⟺ z = kπ，故零点为全体整数倍的 π，最小正实数解是 π。

### f_cv_20（复变函数概念，3 分）

设复变函数 w = f(z) = z²，z = x + yi，则 f 的实部 u(x, y) 在点 z = 1 + i 处的值是 ______。

**答案：**`0`

> 解析：(x + yi)² = (x² - y²) + 2xyi，所以 u = x² - y²，v = 2xy。代入 x = 1, y = 1 得 u(1, 1) = 1 - 1 = 0，v(1, 1) = 2。

## 四、计算题（入库 12 题）

### x_cv_01（四则运算，5 分）

设 z₁ = 1 + 2i，z₂ = 3 - i，求 z₁ + z₂、z₁z₂、z₁/z₂。

**答案：**z₁ + z₂ = `4+i`；z₁z₂ = `5+5i`；z₁/z₂ = `1/10+7/10i`

> 解析：加减只做实部实部、虚部虚部：z₁ + z₂ = (1+2i) + (3-i) = 4 + i。乘法按 (a+bi)(c+di) = (ac - bd) + (ad + bc)i：z₁z₂ = (1+2i)(3-i) = 3 - i + 6i - 2i² = 3 + 5i + 2 = 5 + 5i。除法先有理化：z₁/z₂ = (1+2i)(3+i)/((3-i)(3+i)) = (3 + i + 6i + 2i²)/(9 + 1) = (3 + 7i - 2)/10 = (1 + 7i)/10 = 1/10 + 7/10i。

### x_cv_02（共轭与倒数，5 分）

设 z = 2 + 3i，求 z + z̄、z·z̄、1/z。

**答案：**z + z̄ = `4`；z·z̄ = `13`；1/z = `2/13-3/13i`

> 解析：z̄ = 2 - 3i。z + z̄ = (2+3i) + (2-3i) = 4（相当于 2Re z）。z·z̄ = (2+3i)(2-3i) = 4 - 6i + 6i - 9i² = 4 + 9 = 13 = |z|²。1/z = z̄/|z|² = (2-3i)/13 = 2/13 - 3/13i。

### x_cv_03（幂与根，5 分）

设 z = 1 + i，求 z²、z⁴、z⁸。

**答案：**z² = `2i`；z⁴ = `-4`；z⁸ = `16`

> 解析：z² = (1+i)² = 1 + 2i + i² = 2i；z⁴ = (z²)² = (2i)² = 4i² = -4；z⁸ = (z⁴)² = (-4)² = 16。也可以用棣莫弗公式：1+i = √2(cos π/4 + i sin π/4)，故 zⁿ = 2^{n/2}(cos nπ/4 + i sin nπ/4)。

### x_cv_04（幂与根，5 分）

求方程 z³ = 1 的三个根。

**答案：**w₁ = `1`；w₂ = `-1/2+√3i/2`；w₃ = `-1/2-√3i/2`

> 解析：z = r(cos θ + i sin θ)，由 z³ = 1 = 1·(cos 0 + i sin 0) 得 r³ = 1 即 r = 1，3θ = 2kπ，即 θ = 2kπ/3 (k = 0, 1, 2)。故三个根为 1，cos(2π/3) + i sin(2π/3) = -1/2 + (√3/2)i，以及 cos(4π/3) + i sin(4π/3) = -1/2 - (√3/2)i。

### x_cv_05（模与辐角，5 分）

设 z = 1 + i，求 |z|、|z|²、Arg z。

> 复平面图解： z = 1 + i；|z| = √2；Arg z = π/4

**答案：**|z| = `√2`；|z|² = `2`；Arg z = `π/4`

> 解析：|z| = √(x² + y²) = √(1² + 1²) = √2；|z|² = x² + y² = 2；z 在第一象限且 tan θ = 1，故主值 Arg z = π/4。

### x_cv_06（棣莫弗公式，5 分）

设 z = cos π/6 + i sin π/6 = √3/2 + i/2，求 z³、z⁶、z¹²。

**答案：**z³ = `i`；z⁶ = `-1`；z¹² = `1`

> 解析：由棣莫弗公式 zⁿ = cos nθ + i sin nθ，θ = π/6：z³ = cos π/2 + i sin π/2 = i；z⁶ = cos π + i sin π = -1；z¹² = cos 2π + i sin 2π = 1。

### x_cv_07（复数的表示，5 分）

设 z = 2(cos π/6 + i sin π/6)，求 z 的代数形式、|z| 与 Arg z。

**答案：**z 的代数形式 = `√3+i`；|z| = `2`；Arg z = `π/6`

> 解析：实部 = 2cos π/6 = 2 × (√3/2) = √3，虚部 = 2sin π/6 = 2 × (1/2) = 1，故 z = √3 + i。|z| = √(3 + 1) = 2，与三角形式中的系数一致；z 在第一象限，Arg z = π/6。

### x_cv_08（四则运算，5 分）

设 z₁ = 2 + i，z₂ = 1 - i，求 z₁ + z₂、z₁ - z₂、z₁z₂。

**答案：**z₁ + z₂ = `3`；z₁ - z₂ = `1+2i`；z₁z₂ = `3-i`

> 解析：z₁ + z₂ = (2+i) + (1-i) = 3（虚部相消）；z₁ - z₂ = (2+i) - (1-i) = 1 + 2i；z₁z₂ = (2+i)(1-i) = 2 - 2i + i - i² = 2 - i + 1 = 3 - i。

### x_cv_09（幂与根，5 分）

求方程 z² = 4i 的两个根。

**答案：**w₁ = `√2+√2i`；w₂ = `-√2-√2i`

> 解析：把 4i 写成 4(cos π/2 + i sin π/2)。由 z = r(cos θ + i sin θ) 与 z² = 4(cos π/2 + i sin π/2) 比较系数得 r² = 4 即 r = 2，2θ = π/2 + 2kπ 即 θ = π/4 或 θ = π/4 + π。故 w₁ = 2(cos π/4 + i sin π/4) = √2 + √2i，w₂ = -√2 - √2i。验证：(√2 + √2i)² = 2 + 4i + 2i² = 4i ✓。

### x_cv_10（复三角与双曲函数，5 分）

求复正弦函数 sin z 与双曲正弦函数 sinh z 的周期。

**答案：**sin z 的周期 = `2π`；sinh z 的周期 = `2πi`

> 解析：sin z = (e^{iz} - e^{-iz})/(2i)。由 e^{i(z+2π)} = e^{iz} 得 sin(z+2π) = sin z，而 sin(z+π) = -sin z ≠ sin z，故 sin z 的（最小正）周期是 2π。sinh z = (e^z - e^{-z})/2，sinh(z + 2πi) = (e^z·e^{2πi} - e^{-z}·e^{-2πi})/2 = (e^z - e^{-z})/2 = sinh z（因为 e^{2πi} = 1），故 sinh z 的周期是 2πi。

### x_cv_11（复幂函数，5 分）

按主值定义 z^α = e^{α Log z}，计算 ((-1)²)^{1/2} 与 (-1)^{2·(1/2)} 的值，并据此说明幂律 (z^α)^β = z^{αβ} 是否成立。

**答案：**((-1)²)^{1/2} = `1`；(-1)^{2·(1/2)} = `-1`

> 解析：先算内层：(-1)² = 1，再取 1/2 次幂得 1/2 次根 1^{1/2} = 1。而按幂律直接算：(-1)^{2·(1/2)} = (-1)^1 = -1。1 ≠ -1，说明复数域中幂律 (z^α)^β = z^{αβ} 并不总成立——因为 Log(-1) = i(2k+1)π 是多值的，取不同 k 会得到不同的结果。

### x_cv_12（复变函数概念，5 分）

设复变函数 w = f(z) = z²，z = x + yi。求 u(x, y)、v(x, y) 在点 z = 1 + i 处的值，以及 f(1 + i)。

**答案：**u(1, 1) = `0`；v(1, 1) = `2`；f(1 + i) = `2i`

> 解析：(x + yi)² = x² + 2xyi + y²i² = (x² - y²) + 2xyi，所以 u = x² - y²，v = 2xy。代入 x = 1, y = 1：u(1, 1) = 1 - 1 = 0，v(1, 1) = 2×1×1 = 2，于是 f(1 + i) = 0 + 2i = 2i（与直接算 (1+i)² = 2i 一致）。
