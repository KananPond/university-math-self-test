# 复变函数题库数据格式（bank 包）

本文件是题库的唯一格式契约。所有题库文件都必须严格遵守，否则
`build_paper.py` / `verify_paper.py` / 抽题服务会报错。

## 总规则

- 每个题库文件是一个 Python 模块，只包含数据，不写逻辑。
- 所有字符串使用 UTF-8；答案统一写成字符串。
- 所有 id 在整份题库中必须唯一，前缀区分题型：
  `c_cv_` 选择题、`j_cv_` 判断题、`f_cv_` 填空题、`x_cv_` 计算题。
- 解析、题目说明一律使用中文。
- 每道题必须带 `kp`（知识点标签），闪电训练按它分组，取值见下表。

## 知识点标签（kp，受控词表）

| kp | 含义 |
|----|------|
| `复数的表示` | 代数形式 ↔ 指数形式 ↔ 三角形式 的互化 |
| `模与辐角` | \|z\|、arg z 与 Arg z、辐角主值 |
| `四则运算` | 复数加、减、乘、除 |
| `共轭与倒数` | z̄、1/z、\|z̄z\| 等恒等式 |
| `幂与根` | zⁿ、开 n 次方、方程 zⁿ = w 的根 |
| `棣莫弗公式` | (cosθ + i sinθ)ⁿ = cos nθ + i sin nθ |
| `复指数函数` | eᶻ = eˣ(cos y + i sin y)、周期 2πi |
| `复对数函数` | log z / Log z、支路与割线、乘法律 |
| `复幂函数` | zᵅ = e^{α Log z}、多值性与幂律失效 |
| `复三角与双曲函数` | sin z、cos z、sinh z、cosh z 的复数定义 |
| `复变函数概念` | 定义域、u(x,y) 与 v(x,y)、映射观念 |

> 本系统以「复数的表示与运算」为核心，题量应明显偏向
> `复数的表示`、`模与辐角`、`四则运算`、`共轭与倒数`、`幂与根`、
> `棣莫弗公式` 六项。

## 答案类型（answer_type）

判分使用 `bank/complex_ref.py` 的精确运算，不存在浮点误差。

| answer_type | 含义 | 作答写法 | 示例标准答案 |
|--------------|------|----------|--------------|
| `complex` | 复数 | `a+bi`、`bi`、`i`、`-i`、纯实数 | `3+4i`、`-i`、`1/2-1/2i` |
| `number` | 实数（可含根式） | `5`、`-3/2`、`0.75`、`√13`、`2√3`、`√3/2` | `5`、`√13` |
| `angle` | π 的有理倍数（辐角） | `π/4`、`3π/4`、`-π/2`、`π`、`0` | `π/4` |

- 角度一律用 **π 的倍数** 表示，不用度数。
- `√3/2` 按惯例是 (√3)÷2；需要 √(3/2) 请写成 `√(3/2)`。
- 纯虚的根式建议写成 `√3i/2`（等价写法 `√3/2i` 也可被解析器正确识别）。
- 含 π 的写法支持 `π`、`π/4`、`3π/4`、`iπ`、`-iπ/2`、`2πi`。
- **标准答案可以是字符串，也可以是字符串列表**：列表表示「答出其中任意一个即算对」
  （例如 z² = −1 的根可以答 `i` 或 `-i`）。

## 题面图形（figures）

题面、选项中用 `[[key]]` 标记占位，`key` 对应本题 `figures` 字典里的一个图形；
下发后由前端 canvas 画成复平面图解。

```python
"figures": {
    "P": {"kind": "point", "z": "3+4i", "label": "z",
          "show": ["radius", "angle", "conj"]},
}
```

| kind | 字段 | 含义 |
|------|------|------|
| `point` | `z`、`label`、`show` | 复平面上标出一点；`show` 可含 `radius`（模）、`angle`（辐角弧）、`conj`（共轭对称点）、`proj`（实虚部投影虚线） |
| `roots` | `n`、`radius`、`label` | 在半径 radius 的圆上标出 n 次单位根 |
| `ops` | `z1`、`z2`、`label1`、`label2` | 同时标出 z₁、z₂ 与它们的乘积 z₁z₂，体现「乘 = 旋转 + 伸缩」 |
| `plane` | `points`、`circles` | 任意平面图；`points` 为 `[{"z": "1+i", "label": "z₁"}]`，`circles` 为 `[{"radius": 1, "label": "C"}]` |

## 一、选择题（CHOICE）

```python
{
    "id": "c_cv_01",
    "score": 3,
    "stem": "复数 z = 1 + i 的模是（　　）。",
    "options": ["1", "√2", "2", "1/2"],
    "answer": 1,                    # 正确选项下标 0~3
    "kp": "模与辐角",
    "figures": {...},               # 可选
    "verify": {"kind": "modulus", "z": "1+i"},   # 可选，机械复核
    "explain": "|1+i| = √(1² + 1²) = √2。",
}
```

## 二、判断题（JUDGE）

```python
{
    "id": "j_cv_01",
    "score": 2,
    "stem": "arg z 与 Arg z 是同一个概念。",
    "answer": False,                # 必须是 Python 布尔值
    "kp": "模与辐角",
    "explain": "arg z 多值（θ + 2kπ），Arg z 取主值 ∈ (−π, π]。",
}
```

## 三、填空题（FILL，数值 / 复数答案）

```python
{
    "id": "f_cv_01",
    "score": 3,
    "stem": "复数 z = 3 + 4i 的模是 ______。",
    "answer": "5",                  # 字符串，或字符串列表（任一命中即算对）
    "answer_type": "number",        # number | complex | angle
    "kp": "模与辐角",
    "figures": {...},               # 可选
    "verify": {"kind": "modulus", "z": "3+4i"},
    "explain": "|z| = √(3² + 4²) = 5。",
}
```

判分：把作答解析成精确实数 / 复数后与标准答案**精确比对**，全对得分，否则零分。
作答支持 `3/4`、`0.75`、`-i`、`√13`、`π/4` 等写法。

## 四、计算题（CALC，多空答案）

```python
{
    "id": "x_cv_01",
    "score": 5,
    "stem": "设 z₁ = 1 + 2i，z₂ = 3 − i，求 z₁ + z₂、z₁z₂、z₁/z₂。",
    "blanks": [
        {"label": "z₁ + z₂", "answer": "4+i", "answer_type": "complex"},
        {"label": "z₁z₂", "answer": "5+5i", "answer_type": "complex"},
        {"label": "z₁/z₂", "answer": "1/4+5/4i", "answer_type": "complex"},
    ],
    "kp": "四则运算",
    "figures": {...},               # 可选
    "verify": {"kind": "op", "op": "mul", "left": "1+2i", "right": "3-i",
               "blank": 1},         # 指定校验第几个空
    "explain": "……",
}
```

判分：逐空精确比对，**按正确空数比例给分**
（得分 = round(满分 × 正确空数 / 空数)）。

## verify 校验说明（供 verify_paper.py 机械复核答案）

| kind | 参数 | 复核内容 |
|------|------|----------|
| `op` | `op`、`left`、`right`、`blank?` | 答案 = z₁ + z₂ / z₁ − z₂ / z₁z₂ / z₁/z₂ |
| `modulus` | `z` | 答案 = \|z\| |
| `arg` | `z` | 答案 = Arg z（π 的倍数） |
| `pow` | `z`、`n` | 答案 = zⁿ |
| `conj` | `z` | 答案 = z̄ |
| `inv` | `z` | 答案 = 1/z |
| `root_of` | `z`、`n` | 答案满足 wⁿ = z 且 w ≠ 0 |
| `roots_of_unity` | `n` | 答案属于 n 次单位根集合 |
| `abs_sq` | `z` | 答案 = \|z\|² |

`op` 支持的运算名：`add`、`sub`、`mul`、`div`。
`blank` 省略时校验第一个空；选择填空题用 `option` 指定选项下标。
