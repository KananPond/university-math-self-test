## 一、选择题（入库 20 题）

### c_la_01（一、选择题，3 分）

设 A 是 3×4 矩阵，B 是 4×2 矩阵，则乘积 AB 的阶数是（　　）。

- A. 3×2
- B. 4×2
- C. 3×4
- D. 4×4

**答案：`A`（3×2）**

> 解析：AB 的行数等于左矩阵 A 的行数 3，列数等于右矩阵 B 的列数 2，故 AB 是 3×2 矩阵。可乘条件是 A 的列数等于 B 的行数，这里都是 4。

### c_la_02（一、选择题，3 分）

设 A、B 都是 n 阶方阵，下列等式中恒成立的是（　　）。

- A. (A+B)² = A² + 2AB + B²
- B. (AB)ᵀ = AᵀBᵀ
- C. |AB| = |A||B|
- D. AB = BA

**答案：`C`（|AB| = |A||B|）**

> 解析：矩阵乘法一般不满足交换律，AB ≠ BA，因此 (A+B)² 的中间项是 AB + BA 而不是 2AB；转置运算满足 (AB)ᵀ = BᵀAᵀ；只有行列式乘法 |AB| = |A||B| 恒成立。

### c_la_03（一、选择题，3 分）

行列式 

```
|1  2|
|3  4|
```
 的值是（　　）。

- A. -2
- B. 2
- C. -10
- D. 10

**答案：`A`（-2）**

> 解析：二阶行列式等于主对角线乘积减次对角线乘积：1×4 − 2×3 = 4 − 6 = −2。

### c_la_04（一、选择题，3 分）

设 A 为 n 阶方阵，且 |A| = 2，则 |2A| =（　　）。

- A. 2
- B. 4
- C. 2ⁿ
- D. 2ⁿ⁺¹

**答案：`D`（2ⁿ⁺¹）**

> 解析：数乘行列式要把 k 提出来乘 n 次：|kA| = kⁿ|A|，故 |2A| = 2ⁿ·2 = 2ⁿ⁺¹。注意与 k|A| = 2 区分。

### c_la_05（一、选择题，3 分）

把向量组 α₁ = (1, 2, 3)、α₂ = (2, 4, 6)、α₃ = (1, 1, 1) 按行排成矩阵 

```
⎡ 1  2  3 ⎤
⎢ 2  4  6 ⎥
⎣ 1  1  1 ⎦
```
，则该向量组的秩是（　　）。

- A. 3
- B. 2
- C. 1
- D. 0

**答案：`B`（2）**

> 解析：α₂ = 2α₁，故 α₁、α₂ 线性相关；而 α₃ 与 α₁ 对应分量不成比例，故 α₁、α₃ 线性无关。极大无关组含 2 个向量，秩为 2。

### c_la_06（一、选择题，3 分）

n 元齐次线性方程组 Ax = 0 有非零解的充分必要条件是（　　）。

- A. r(A) = n
- B. r(A) < n
- C. |A| ≠ 0
- D. A 可逆

**答案：`B`（r(A) < n）**

> 解析：齐次方程组总有零解；当且仅当系数矩阵的秩小于未知量个数 n 时才出现自由未知量，从而有非零解。A 可逆（|A| ≠ 0，r(A) = n）时只有零解。

### c_la_07（一、选择题，3 分）

设 λ = 2 是矩阵 A 的一个特征值，则 A² 的特征值中必有（　　）。

- A. 2
- B. 4
- C. 8
- D. 16

**答案：`B`（4）**

> 解析：若 Ax = λx（x ≠ 0），则 A²x = A(λx) = λ²x，故 λ² = 4 是 A² 的特征值。一般地，f(A) 的特征值是 f(λ)。

### c_la_08（一、选择题，3 分）

设 n 阶矩阵 A 满足 A² = A，则 A 的特征值只能是（　　）。

- A. 0 或 1
- B. 1 或 −1
- C. 0 或 2
- D. 任意实数

**答案：`A`（0 或 1）**

> 解析：设 Ax = λx，则 A²x = λ²x；又 A² = A，故 λ²x = λx，即 (λ² − λ)x = 0。由 x ≠ 0 得 λ(λ − 1) = 0，故 λ = 0 或 1。

### c_la_09（一、选择题，3 分）

二次型 f(x, y, z) = x² + 2y² + z² + 2xy 的矩阵为 

```
⎡ 1  1  0 ⎤
⎢ 1  2  0 ⎥
⎣ 0  0  1 ⎦
```
，则该二次型的秩是（　　）。

- A. 1
- B. 2
- C. 3
- D. 4

**答案：`C`（3）**

> 解析：二次型的秩就是它对应矩阵的秩。|Q| = 1×(2−0) − 1×(1−0) = 1 ≠ 0，故 r(Q) = 3，二次型的秩为 3。

### c_la_10（一、选择题，3 分）

设 A、B 均为 n 阶方阵，且 AB = O，则下列结论正确的是（　　）。

- A. A = O 或 B = O
- B. |A| = 0 或 |B| = 0
- C. BA = O
- D. (A + B)² = A² + B²

**答案：`B`（|A| = 0 或 |B| = 0）**

> 解析：两边取行列式得 |A||B| = |O| = 0，故 |A| = 0 或 |B| = 0。但矩阵乘法存在零因子，A、B 可以都非零（例如两个非零对角矩阵错位相乘），故 A = O、B = O、BA = O 都不一定成立。

### c_la_11（一、选择题，3 分）

下列矩阵中，可逆的是（　　）。

- A.

⎡ 1  2 ⎤
⎣ 2  4 ⎦
```

- B. 

```
⎡ 1  2 ⎤
⎣ 3  5 ⎦

- C. 

```
⎡ 0  1 ⎤
⎣ 0  2 ⎦
```

- D. 

```
⎡ 3  6 ⎤
⎣ 1  2 ⎦

**答案：`B`（[[mB]]）**

### c_la_13（一、选择题，3 分）

向量 β 可由向量组 α₁, α₂ 线性表示的充分必要条件是（　　）。

- A. r(α₁, α₂) = r(α₁, α₂, β)
- B. α₁, α₂ 线性无关
- C. β ≠ 0
- D. α₁, α₂ 线性相关

**答案：`A`（r(α₁, α₂) = r(α₁, α₂, β)）**

> 解析：β 能由 α₁, α₂ 线性表示 ⟺ 以 α₁, α₂ 为系数列、β 为常数列的方程组有解 ⟺ 增广矩阵与系数矩阵的秩相等。

### c_la_14（一、选择题，3 分）

设 n 元齐次线性方程组 Ax = 0 满足 r(A) = r < n，则它的基础解系含有（　　）个解向量。

- A. r
- B. n − r
- C. n
- D. r − n

**答案：`B`（n − r）**

> 解析：基础解系所含向量个数等于自由未知量个数，即 n − r(A) = n − r。

### c_la_15（一、选择题，3 分）

下列命题中正确的是（　　）。

- A. 若 α₁, α₂ 线性相关，则 α₁, α₂ 中每一个向量都可由其余向量线性表示
- B. 若 α₁, α₂, α₃ 线性无关，则 α₁+α₂, α₂+α₃, α₃+α₁ 也线性无关
- C. 含有零向量的向量组可能线性无关
- D. 线性无关的向量组再添加一个向量后仍然线性无关

**答案：`B`（若 α₁, α₂, α₃ 线性无关，则 α₁+α₂, α₂+α₃, α₃+α₁ 也线性无关）**

> 解析：第二项对：设 k₁(α₁+α₂) + k₂(α₂+α₃) + k₃(α₃+α₁) = 0，整理得 (k₁+k₃)α₁ + (k₁+k₂)α₂ + (k₂+k₃)α₃ = 0，由无关性知该齐次方程组只有零解。第一项错：只有“某一个”向量可由其余表示；第三、四项均与线性相关性的基本定理矛盾。

### c_la_17（一、选择题，3 分）

设实对称矩阵

⎡ 1  2 ⎤
⎣ 2  1 ⎦
```
，则与 A 相似的对角矩阵 Λ 可以是（　　）。

- B.

### c_la_18（一、选择题，3 分）

设 A 为 n 阶实对称矩阵，则下列结论一定成立的是（　　）。

- A. A 的特征值都是实数
- B. A 一定可逆
- C. A 的特征值都不为零
- D. A 一定是对角矩阵

**答案：`A`（A 的特征值都是实数）**

> 解析：实对称矩阵的特征值必为实数，且不同特征值对应的特征向量正交、必可正交对角化。但实对称矩阵不一定可逆（例如含零特征值的[[1,1],[1,1]]），也不一定已经是对角矩阵。

### c_la_19（一、选择题，3 分）

n 阶方阵 A 可相似对角化的充分必要条件是（　　）。

- A. A 有 n 个互不相同的特征值
- B. A 有 n 个线性无关的特征向量
- C. A 是实对称矩阵
- D. r(A) = n

**答案：`B`（A 有 n 个线性无关的特征向量）**

> 解析：A 可对角化 ⟺ A 有 n 个线性无关的特征向量 ⟺ 对每个 k 重特征值，属于它的线性无关特征向量恰有 k 个。“有 n 个互不相同的特征值”与“实对称”都只是充分条件而非必要条件。

### c_la_20（一、选择题，3 分）

二次型 f(x, y, z) = x² + y² + z² + 2xy 的矩阵为 

```
⎡ 1  1  0 ⎤
⎢ 1  1  0 ⎥
⎣ 0  0  1 ⎦
```
，则 f 是（　　）。

- A. 正定二次型
- B. 半正定（非正定）二次型
- C. 负定二次型
- D. 不定二次型

**答案：`B`（半正定（非正定）二次型）**

> 解析：二阶顺序主子式 Δ₂ = 1×1 − 1×1 = 0，不满足正定的充要条件，故不是正定。配方得 f = (x+y)² + z² ≥ 0 且能取到 0（如 x = −y, z = 0），但 f 不恒为零，故半正定。

## 二、判断题（入库 16 题）

### j_la_01（二、判断题，2 分）

若 n 阶方阵 A 与 B 可交换（即 AB = BA），则 (A + B)² = A² + 2AB + B²。

**答案：对**

> 解析：(A+B)² = A² + AB + BA + B²，由 AB = BA 得中间两项相等，合并为 2AB。等式一般不成立的原因正是乘法不可交换，本题恰好给了交换条件。

### j_la_02（二、判断题，2 分）

两个非零矩阵的乘积一定是非零矩阵。

**答案：错**

> 解析：矩阵乘法存在零因子。例如 [[1,1],[1,1]] × [[1,1],[−1,−1]] = O，两个因子都不是零矩阵。

### j_la_03（二、判断题，2 分）

若 n 阶方阵 A 的行列式 |A| = 0，则 A = O。

**答案：错**

> 解析：行列式为零只说明 A 不可逆，元素可以全不为零，例如 [[1,2],[2,4]] 的行列式为 0 但不是零矩阵。

### j_la_04（二、判断题，2 分）

对任意 n 阶方阵 A，都有 |Aᵀ| = |A|。

**答案：对**

> 解析：行列式与其转置的值相等，这是行列式的经典性质。

### j_la_05（二、判断题，2 分）

设 A 为 n 阶可逆矩阵（n ≥ 2），则 |A*| = |A|ⁿ⁻¹。

**答案：对**

> 解析：由 AA* = |A|E 取行列式得 |A||A*| = |A|ⁿ，A 可逆时 |A| ≠ 0，两边除以 |A| 即得 |A*| = |A|ⁿ⁻¹。

### j_la_06（二、判断题，2 分）

若向量组 α₁, …, αₛ 与向量组 β₁, …, β_t 等价，则两组所含向量的个数一定相等。

**答案：错**

> 解析：等价只要求两组能互相线性表示，等价的是它们的秩，向量个数可以不同。例如 (1,0),(0,1) 与 (1,0),(0,1),(1,1) 等价，但个数分别为 2 和 3。

### j_la_07（二、判断题，2 分）

若矩阵 A 的秩 r(A) = r，则 A 的所有 r + 1 阶子式（若存在）都等于零。

**答案：对**

> 解析：矩阵的秩就是最高阶非零子式的阶数：存在 r 阶非零子式，而所有 r+1 阶子式全为零。

### j_la_08（二、判断题，2 分）

n 元齐次线性方程组 Ax = 0 一定有非零解。

**答案：错**

> 解析：齐次方程组必有零解；当 r(A) = n 时只有零解，仅当 r(A) < n 时才有非零解。

### j_la_09（二、判断题，2 分）

A 为 n 阶方阵时，非齐次线性方程组 Ax = b 有唯一解的充分必要条件是 r(A) = r(A, b) = n。

**答案：对**

> 解析：r(A) = r(A,b) < n 时有无穷多解；r(A) < r(A,b) 时无解；r(A) = r(A,b) = n 时有唯一解。

### j_la_10（二、判断题，2 分）

设 λ ≠ 0 是可逆矩阵 A 的特征值，则 1/λ 是 A⁻¹ 的特征值。

**答案：对**

> 解析：由 Ax = λx（x ≠ 0）得 x = λA⁻¹x，即 A⁻¹x = (1/λ)x，故 1/λ 是 A⁻¹ 的特征值。

### j_la_11（二、判断题，2 分）

相似矩阵的秩可能不同。

**答案：错**

> 解析：相似矩阵一定等价，它们的秩、行列式、特征多项式与特征值都相同。

### j_la_12（二、判断题，2 分）

若矩阵 A 与 B 等价，则 A 与 B 一定相似。

**答案：错**

> 解析：等价只要求秩相同（可经初等变换互化），相似还要求存在可逆矩阵 P 使 P⁻¹AP = B。秩相同的矩阵未必有相同的特征多项式，故不一定相似。

### j_la_13（二、判断题，2 分）

任何 n 阶方阵都可以相似对角化。

**答案：错**

> 解析：可对角化当且仅当有 n 个线性无关的特征向量。例如 [[1,1],[0,1]] 是若尔当块，线性无关特征向量只有 1 个，不可对角化。

### j_la_14（二、判断题，2 分）

实对称矩阵必可正交相似对角化。

**答案：对**

> 解析：实对称矩阵的特征值全为实数，且必存在正交矩阵 Q，使 Q⁻¹AQ = QᵀAQ 为对角矩阵（实对称矩阵的谱定理）。

### j_la_15（二、判断题，2 分）

二次型 f = xᵀAx（A 实对称）正定的充分必要条件是 |A| > 0。

**答案：错**

> 解析：|A| > 0 只是必要条件之一。正定的充要条件是各阶顺序主子式全大于零（或特征值全大于零）。例如 A = [[−1,0],[0,−2]]，|A| = 2 > 0 但 f 是负定的。

### j_la_16（二、判断题，2 分）

设 A 为 n 阶实对称矩阵，若 A 的特征值全为正数，则二次型 f = xᵀAx 正定。

**答案：对**

> 解析：正交变换把 f 化为标准形 λ₁y₁² + … + λₙyₙ²，特征值全正时对任意 x ≠ 0 都有 f > 0，故正定。

## 三、填空题（入库 16 题）

### f_la_01（三、填空题，3 分）

计算三阶行列式 

```
| 1   2   3|
| 4   5   6|
| 7   8  10|
```
 = ______。

**答案：**`-3`

> 解析：对角线法则或按第一行展开：1·(5×10 − 6×8) − 2·(4×10 − 6×7) + 3·(4×8 − 5×7) = 2 + 4 − 9 = −3。

### f_la_02（三、填空题，3 分）

行列式 

```
|1  1  1|
|1  2  3|
|1  4  9|
```
 = ______。

**答案：**`2`

> 解析：这是范德蒙德行列式，值为 (x₂−x₁)(x₃−x₁)(x₃−x₂) = 1×2×1 = 2。也可用列变换后按定义计算。

### f_la_03（三、填空题，3 分）

设 A 为 3 阶可逆矩阵且 |A| = 3，则 |A⁻¹| = ______。

**答案：**`1/3`

> 解析：由 AA⁻¹ = E 取行列式得 |A||A⁻¹| = 1，故 |A⁻¹| = 1/|A| = 1/3。

### f_la_04（三、填空题，3 分）

设 3 阶方阵 A 的特征值为 1, 2, 3，则 |A + E| = ______。

**答案：**`24`

> 解析：A + E 的特征值为 λ + 1，即 2, 3, 4，行列式等于特征值之积 2×3×4 = 24。

### f_la_05（三、填空题，3 分）

向量 α = 

```
⎡ 1 ⎤
⎢ 2 ⎥
⎣ 2 ⎦
```
 的长度（模）‖α‖ = ______。

**答案：**`3`

> 解析：‖α‖ = √(1² + 2² + 2²) = √9 = 3。

### f_la_06（三、填空题，3 分）

矩阵 

```
⎡ 1  2 ⎤
⎣ 2  4 ⎦
```
 的秩 r(A) = ______。

**答案：**`1`

> 解析：第二行是第一行的 2 倍，行阶梯形只剩 1 个非零行，故 r(A) = 1。

### f_la_07（三、填空题，3 分）

### f_la_09（三、填空题，3 分）

### x_la_10（四、计算题，5 分）

设矩阵 

```
⎡ 1  0  2 ⎤
⎢ 0  1  0 ⎥
⎣ 0  0  1 ⎦
```
，求 A⁻¹。

**答案：**```
⎡  1   0  -2 ⎤
⎢  0   1   0 ⎥
⎣  0   0   1 ⎦
```

> 解析：A = E + N，N = [[0,0,2],[0,0,0],[0,0,0]] 满足 N² = O，故 A⁻¹ = E − N = [[1,0,−2],[0,1,0],[0,0,1]]。用初等行变换 (A | E) → (E | A⁻¹) 结果相同。
