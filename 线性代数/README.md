# 线性代数考试模拟系统

一套**本地运行的线性代数考试模拟工具**：从题库随机抽题、浏览器作答、
题面矩阵全部**图形化渲染**（canvas 热力图 + 悬停取值 + 分数排版），
交卷后服务端用精确分数运算判分，并给出逐题解析与错题复盘。

零第三方依赖（Python 标准库 + 原生 JavaScript），断网可用，
成绩与作答记录都留在本机。

## 快速开始

**Windows**：双击 `web_exam/start.bat`（本系统只需 Python，无需 gcc）。

**WSL / Linux / macOS**：

```bash
cd web_exam
./start.sh
```

启动脚本会检查 `python3`、检测端口占用并自动打开浏览器。
浏览器打开后先看到起始页，点 **“开始考试”** 才开始 120 分钟倒计时。

停止服务：在启动脚本窗口按 `Ctrl + C`。
换端口用 `./start.sh 9000`，只启动不开浏览器用 `./start.sh --no-open`。
默认端口 `8766`（与 C 语言版模板的 8765 互不冲突，可同时运行）。

## 考试流程

1. **起始页** —— 显示抽题号、题量构成、考试时间，此时不计时
2. **开始考试** —— 点按钮后计时启动、试卷展开
3. **作答** —— 选择/判断点选项；填空题直接输入数值（支持 `3/4`、
   `0.75`、`2`）；计算题在矩阵表格里作答，右侧**同步画出矩阵图形预览**
4. **实时得分** —— 左侧栏随作答即时更新当前得分（只回总分，不泄露对错）
5. **交卷评分** —— 服务端精确判分，弹出成绩单与逐题解析，
   正确答案中的矩阵同样以图形呈现
6. **保存记录** —— 成绩与错题清单写入 `web_exam/records/`

中途刷新页面：倒计时按真实时间继续，作答不丢（localStorage）。

## 图形化矩阵能力

| 位置 | 能力 |
|------|------|
| 题面 | 所有矩阵/行列式/增广矩阵用 canvas 绘制：方括号、行列式竖线、增广虚线；元素按正负与大小着色（正蓝、负红、零灰的热力图）；悬停显示“第几行第几列”与数值；分数按上下结构排版 |
| 计算题作答 | 固定形状的矩阵输入表格 + 实时图形预览，写完立刻能看到自己答案的“样子” |
| 成绩单 / 解析 | 你的作答与正确答案的矩阵并排图形对比 |
| 矩阵可视化实验台 | 独立页面 `viz.html`：输入任意 1×1～4×4 矩阵，实时查看热力图、行列式、迹、秩、逆矩阵、特征值；2×2 矩阵还有**线性变换动画**（坐标网格变形、î/ĵ 的像、单位正方形变成面积 = |det| 的平行四边形、特征方向） |

实验台从考试页右上角“矩阵可视化实验台”进入，也可单独访问
`http://127.0.0.1:8766/viz.html`。

## 题库与抽题

题库共 **62 题**，每次开考随机抽 **32 题**组成一份 100 分的试卷：

| 大题 | 入库 | 每卷抽取 | 每题 | 每卷分值 | 判分方式 |
|------|------|----------|------|----------|----------|
| 一、选择题 | 20 | 10 | 3 分 | 30 | 选项比对 |
| 二、判断题 | 16 | 8 | 2 分 | 16 | 对 / 错比对 |
| 三、填空题 | 16 | 8 | 3 分 | 24 | 精确分数比对（全对得分） |
| 四、计算题 | 10 | 6 | 5 分 | 30 | 矩阵逐元素比例给分；特征向量 / 基础解系按语义判分 |

- 抽题以**随机种子**为唯一依据：同一 seed 必得同一份试卷，
  刷新页面或重启服务都不会换卷；点“换一套题”才重新抽。
- 答案、解析与复核规则全部留在服务端，**前端拿不到**。
- 计算题的分数元素（如 `3/2`）与等值小数（`1.5`）判分等价；
  全部比对基于 `fractions.Fraction` 精确运算，无浮点误差。
- 特征向量题任何非零倍数都判满分；基础解系题任何一组合法
  基础解系都判满分（合法但相关的列给一半份额）。

覆盖知识点：行列式、矩阵运算与逆、伴随矩阵、秩、向量组线性相关性、
线性方程组与基础解系、特征值与特征向量、相似对角化、二次型与正定性。

## 维护题库

试卷、答案、总览都由 `bank/` 派生，**不要直接改生成物**：

```bash
cd 考试服务
# 1. 按 bank/FORMAT.md 修改或新增题目
python build_paper.py     # 重新生成 paper.md / answer_key.md / bank_overview.md
python verify_paper.py    # 必须全部通过
```

`verify_paper.py` 会做三类检查：

1. 题库结构自查（题量、id 唯一、字段完整、矩阵规格与 `[[key]]` 标记可解析）；
2. **答案机械复核**：能用线性代数重算的题目全部用分数精确运算重算
   （行列式、秩、逆、伴随、乘积、方程组解、特征值、特征向量、基础解系等）；
3. 抽题逻辑（每卷 32 题 100 分、同种子可复现、不同种子不同卷）。

改动判分逻辑后还要跑一遍端到端测试：

```bash
cd 考试服务/web_exam
python server.py &          # 先起服务
node tests/web_grading_test.mjs
```

测试覆盖：抽题可复现与答案隔离、前端整卷渲染、实时得分、
满分 / 零分卷、等值小数与分数等价、逐元素比例给分、
特征向量与基础解系语义判分、记录保存。

## 考后复盘

每次交卷后点“保存答题记录”，然后：

```bash
cd 考试服务/web_exam
python review.py             # 自动取最新一条记录，生成错题精讲
python review.py records/xxx.json   # 或指定记录
```

`review.py` 按抽题号复原试卷，逐题给出题面（矩阵画成字符画）、
你的作答、正确答案与解析，输出到 `records/` 下。

## 说明

- 服务只监听 `127.0.0.1`，不对外网开放。
- 本工具面向**个人自测与练习**，不具备监考能力。
- 架构参考同仓库 `模板/exam/web_exam/`（C 语言考试模拟系统）：
  相同的题库 / 抽题 / 判分 / 记录分层与接口约定；
  差异点是判分内核——C 语言版用 gcc 编译运行，
  本系统改为精确分数与矩阵比对，并新增 canvas 矩阵可视化。
