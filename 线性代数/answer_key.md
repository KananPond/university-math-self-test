# 线性代数考试模拟卷 · 参考答案与解析（种子 20261002）

## 一、选择题

**1-1.** `B`（r(A) < n）

> 解析：齐次方程组总有零解；当且仅当系数矩阵的秩小于未知量个数 n 时才出现自由未知量，从而有非零解。A 可逆（|A| ≠ 0，r(A) = n）时只有零解。

**1-2.** `B`（2）

> 解析：α₂ = 2α₁，故 α₁、α₂ 线性相关；而 α₃ 与 α₁ 对应分量不成比例，故 α₁、α₃ 线性无关。极大无关组含 2 个向量，秩为 2。

**1-3.** `A`（A 的特征值都是实数）

> 解析：实对称矩阵的特征值必为实数，且不同特征值对应的特征向量正交、必可正交对角化。但实对称矩阵不一定可逆（例如含零特征值的[[1,1],[1,1]]），也不一定已经是对角矩阵。

**1-4.** `A`（[[o1]]）

> 解析：二阶伴随矩阵口诀：主对角线对调、次对角线变号，A* = [[4, −2], [−3, 1]]。可用 AA* = |A|E 验证：|A| = −2，AA* = (−2)E 成立。

**1-5.** `A`（r(α₁, α₂) = r(α₁, α₂, β)）

> 解析：β 能由 α₁, α₂ 线性表示 ⟺ 以 α₁, α₂ 为系数列、β 为常数列的方程组有解 ⟺ 增广矩阵与系数矩阵的秩相等。

**1-6.** `A`（[[o1]]）

> 解析：特征方程 |A − λE| = (1−λ)² − 4 = 0，得 λ₁ = 3，λ₂ = −1。实对称矩阵必可对角化，Λ = diag(3, −1)。

**1-7.** `B`（半正定（非正定）二次型）

> 解析：二阶顺序主子式 Δ₂ = 1×1 − 1×1 = 0，不满足正定的充要条件，故不是正定。配方得 f = (x+y)² + z² ≥ 0 且能取到 0（如 x = −y, z = 0），但 f 不恒为零，故半正定。

**1-8.** `C`（|AB| = |A||B|）

> 解析：矩阵乘法一般不满足交换律，AB ≠ BA，因此 (A+B)² 的中间项是 AB + BA 而不是 2AB；转置运算满足 (AB)ᵀ = BᵀAᵀ；只有行列式乘法 |AB| = |A||B| 恒成立。

**1-9.** `B`（[[mB]]）

> 解析：方阵可逆当且仅当行列式不为零。|A| = 4 − 4 = 0；|B| = 1×5 − 2×3 = −1 ≠ 0，B 可逆；|C| = 0；|D| = 6 − 6 = 0。

**1-10.** `A`（0 或 1）

> 解析：设 Ax = λx，则 A²x = λ²x；又 A² = A，故 λ²x = λx，即 (λ² − λ)x = 0。由 x ≠ 0 得 λ(λ − 1) = 0，故 λ = 0 或 1。

## 二、判断题

**2-1.** 错

> 解析：相似矩阵一定等价，它们的秩、行列式、特征多项式与特征值都相同。

**2-2.** 对

> 解析：由 AA* = |A|E 取行列式得 |A||A*| = |A|ⁿ，A 可逆时 |A| ≠ 0，两边除以 |A| 即得 |A*| = |A|ⁿ⁻¹。

**2-3.** 错

> 解析：齐次方程组必有零解；当 r(A) = n 时只有零解，仅当 r(A) < n 时才有非零解。

**2-4.** 对

> 解析：由 Ax = λx（x ≠ 0）得 x = λA⁻¹x，即 A⁻¹x = (1/λ)x，故 1/λ 是 A⁻¹ 的特征值。

**2-5.** 错

> 解析：等价只要求秩相同（可经初等变换互化），相似还要求存在可逆矩阵 P 使 P⁻¹AP = B。秩相同的矩阵未必有相同的特征多项式，故不一定相似。

**2-6.** 错

> 解析：可对角化当且仅当有 n 个线性无关的特征向量。例如 [[1,1],[0,1]] 是若尔当块，线性无关特征向量只有 1 个，不可对角化。

**2-7.** 错

> 解析：|A| > 0 只是必要条件之一。正定的充要条件是各阶顺序主子式全大于零（或特征值全大于零）。例如 A = [[−1,0],[0,−2]]，|A| = 2 > 0 但 f 是负定的。

**2-8.** 对

> 解析：(A+B)² = A² + AB + BA + B²，由 AB = BA 得中间两项相等，合并为 2AB。等式一般不成立的原因正是乘法不可交换，本题恰好给了交换条件。

## 三、填空题

**3-1.** `1`

> 解析：未知量 n = 3，r(A) = 2，基础解系含 n − r = 1 个向量。两式相减得 x₃ = 0，代回得 x₁ = −2x₂，基础解系如 (−2, 1, 0)ᵀ。

**3-2.** `-8`

> 解析：|2A| = 2²|A| = 4 × (1×4 − 2×3) = 4 × (−2) = −8。注意 2|A| = −4 与 |2A| = −8 的区别。

**3-3.** `24`

> 解析：A + E 的特征值为 λ + 1，即 2, 3, 4，行列式等于特征值之积 2×3×4 = 24。

**3-4.** `3`

> 解析：‖α‖ = √(1² + 2² + 2²) = √9 = 3。

**3-5.** `1`

> 解析：(α, β) = 1×2 + (−1)×1 + 0×3 = 1。

**3-6.** `2`

> 解析：系数行列式 D = 1×(−1) − 1×1 = −2，Dₓ = 3×(−1) − 1×1 = −4，x = Dₓ/D = 2（y = 1）。

**3-7.** `2`

> 解析：这是范德蒙德行列式，值为 (x₂−x₁)(x₃−x₁)(x₃−x₂) = 1×2×1 = 2。也可用列变换后按定义计算。

**3-8.** `1`

> 解析：特征值满足 |A − 2E| = 0：|a−2, 1; 1, −1| = −(a−2) − 1 = −a + 1 = 0，得 a = 1。

## 四、计算题

**4-1.** ```
⎡  1  -1   0 ⎤
⎢  0   1  -1 ⎥
⎣  0   0   1 ⎦
```

> 解析：对 (A | E) 作初等行变换化成 (E | A⁻¹)，或按 A X = E 逐列解，得 A⁻¹ = [[1,−1,0],[0,1,−1],[0,0,1]]。上三角矩阵的逆仍是上三角矩阵。

**4-2.** ```
⎡     -2     1   ⎤
⎣    3/2  -1/2   ⎦
```

> 解析：|A| = 1×4 − 2×3 = −2。A⁻¹ = (1/|A|)A* = (1/−2)·[[4,−2],[−3,1]] = [[−2,1],[3/2,−1/2]]。

**4-3.** ```
⎡ 1 ⎤
⎣ 1 ⎦
```

> 解析：解 (A − 4E)x = 0，即 [[−1,1],[1,−1]]x = 0，得 x₁ = x₂，取特征向量 (1,1)ᵀ；k(1,1)ᵀ（k ≠ 0）都是正确答案。

**4-4.** ```
⎡ 3  4 ⎤
⎣ 6  8 ⎦
```

> 解析：αβᵀ 的 (i, j) 元 = αᵢβⱼ，即 [[1×3, 1×4], [2×3, 2×4]] = [[3,4],[6,8]]。注意与内积 αᵀβ = 11（1×1）的区别。

**4-5.** ```
⎡ -1   0 ⎤
⎣  0  -1 ⎦
```

> 解析：A² = [[0,1],[−1,0]]·[[0,1],[−1,0]] = [[−1,0],[0,−1]] = −E。连续旋转两个 90° 相当于旋转 180°，向量全部反向。

**4-6.** ```
⎡  1   0  -2 ⎤
⎢  0   1   0 ⎥
⎣  0   0   1 ⎦
```

> 解析：A = E + N，N = [[0,0,2],[0,0,0],[0,0,0]] 满足 N² = O，故 A⁻¹ = E − N = [[1,0,−2],[0,1,0],[0,0,1]]。用初等行变换 (A | E) → (E | A⁻¹) 结果相同。
